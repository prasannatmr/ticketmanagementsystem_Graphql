# Ticket Management System - Laravel GraphQL

A backend-focused Ticket Management System built with Laravel and GraphQL.

## Tech Stack

- PHP
- Laravel
- GraphQL
- MySQL
- Eloquent ORM
- Authentication & Authorization
- API Development

## Features

- User Authentication
- Ticket Creation & Management
- Ticket Status Management
- Priority Management
- User Roles
- Ticket Assignment
- GraphQL Queries & Mutations
- Validation
- Database Relationships
